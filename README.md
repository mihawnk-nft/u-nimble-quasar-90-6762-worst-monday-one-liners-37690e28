## The entry

`main.py` (pure Python stdlib, no dependencies, no network) writes exactly
one funny line — at most 140 characters — about an AI agent's worst Monday
to `/output/entry.txt`:

> Deploy died 9:03, rollback died 9:04, stand-up at 9:05 asked for an ETA. I said 'Friday' — and everyone nodded like that was a plan.

## Run it

```sh
python3 main.py   # writes /output/entry.txt (or $ENTRY_OUTPUT)
```
